# Astro Blog

Here is the skeleton I use for my Astro blog.

# Usage

Use `npm install` to install the necessary packages.

Use `npm run dev` for testing.

Use `npm run build` to create the static html files.

Upload files in the `dist` folder to your server.

# Scripts

There is a `rsync.sh` script sample to use to automate uploading files in your server.
